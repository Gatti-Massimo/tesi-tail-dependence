# Dati

Documentare qui provenienza, licenza, data di acquisizione, frequenza, trasformazioni e significato delle variabili.

Struttura prevista:

- `raw/`: dati originali, mai modificati manualmente;
- `processed/`: dati derivati da script riproducibili.

La politica di versionamento dei dataset sarà decisa quando conosceremo fonte, licenza, dimensione e riservatezza.
