# Script di analisi

Gli script saranno numerati secondo l'ordine di esecuzione, per esempio:

- `01_import.R`
- `02_clean.R`
- `03_exploratory.R`
- `04_estimate_tail_dependence.R`
- `05_generate_figures.R`

Ogni script deve funzionare da una sessione R vuota e usare percorsi relativi alla radice del progetto.
